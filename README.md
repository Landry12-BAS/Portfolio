# Portfolio
Where real-world work meets AI, agentic intelligence, and powerful tools.

Ten live AI systems built for one fictional company, Basalt & Bean Coffee Co. Every
system runs on the site, open to any visitor, with a trace of every step it takes.

| Part | System | Back end |
|---|---|---|
| LS-01 | Support Desk Agent: cited replies to tickets, approved by a person | Django |
| LS-02 | Booking Concierge: multilingual booking chat that can't double-book | Django Channels |
| LS-03 | Invoice Reader: photos and PDFs to checked accounting entries | Flask (async) |
| LS-04 | Contract Radar: every risk tied to the exact clause | Node + TypeScript |
| LS-05 | Data Analyst: plain-language questions to safe SQL | Flask (sync) |
| LS-06 | Incident Commander: AI agents diagnose a simulated outage | Node + TypeScript |
| LS-07 | QA Engineer: a browser agent that writes the test proving each bug | Node + TypeScript |
| LS-08 | Automation Studio: plain language to durable workflows | Node + TypeScript |
| LS-09 | Meeting Recorder: action items linked to the moment they were said | Django |
| LS-10 | Eval Lab: every prompt change gets a score | Flask (async) |

Front end: Next.js, React and TypeScript (TSX). AI: free tiers from Groq, Cloudflare
Workers AI, NVIDIA NIM and OpenRouter, behind one gateway.
