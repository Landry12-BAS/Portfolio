# The LB mark

The logo of Landry Bodjona: LB drawn as an integrated-circuit package. The notch and
the dot mark pin 1, as they do on a real chip. The mark signs every page the way a
manufacturer's logo signs a datasheet.

| File | Use |
|---|---|
| `lb-mark.svg` | Default, from 28 px up |
| `lb-mark-compact.svg` | Below 28 px: favicons and toolbars. No pins, bigger letters |

## Rules

- Ink (`#0F1419`) on white. Never on the green evaluation board, which is reserved
  for live demos.
- Clear space on every side: one pin length, about a ninth of the mark's width.
- Wordmark: LANDRY BODJONA in Archivo Expanded 800, beside the mark.
- The letters are drawn as shapes, so the mark renders the same without the fonts.
  Use the files; don't retype LB as text.
